Event Registration with Limited Capacity

📖 Project Description

This project is a web-based Event Registration System that allows students to register for events with limited capacity. Each event has a maximum number of seats, and once that capacity is reached, no further registrations are allowed.

The system also provides an Admin Panel where administrators can view participants, manage events, and monitor seat availability. Additionally, the system supports email confirmations for successful registrations.

🚀 Features

🧑‍🎓 Student Side

View available events with details such as event name, description, date, and seats left.

Register for events by entering personal details.

Automatic capacity check – Registration is blocked when the event is full.

Display message “Registration Closed – Seats Full” if capacity is reached.

Optional email confirmation after successful registration.

👩‍💼 Admin Side

Login to Admin Panel.

View the list of all participants registered for each event.

Manage event details such as name, date, description, and capacity.

Monitor real-time availability of seats.

🛠️ Tech Stack

Frontend: React.js / HTML / CSS / JavaScript

Backend: Node.js, Express.js

Database: MongoDB with Mongoose

Email Service (Optional): Nodemailer
